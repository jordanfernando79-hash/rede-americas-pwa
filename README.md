# Central de Gestão Manutenção Rede Américas

Aplicativo PWA para gestão integrada da manutenção hospitalar.

## Módulos
- Painel Geral
- RDI
- Qualidade da Água
- Neovero
- Relatórios
- Documentos
- Inventário
- Treinamentos
- Organograma
- Matriz de Comunicação

## Tecnologia
- PWA instalável
- Supabase para banco de dados e autenticação
- Cloudflare para hospedagem
- GitHub para versionamento

## Segurança
Acesso multiusuário com permissões por unidade, módulo e operação.

Não coletar CPF, salário ou endereço residencial dos funcionários.

## Situação
Projeto em desenvolvimento. Primeira versão em preparação.
